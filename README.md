# Cascade Hunter V2

النسخة الأساسية المعتمدة: **2.0.0**، بتاريخ **30 أكتوبر 2026**. محاكاة ورقية ببيانات Binance USDT-M المباشرة. أمر التشغيل الأساسي هو `run_paper_live.py` مع لوحة متابعة خاصة.

## الإعدادات المعتمدة

| الإعداد | القيمة |
|---|---|
| الرصيد الابتدائي للجلسة الجديدة | 100 USDT افتراضي |
| هامش كل صفقة | 10% من رصيد المحفظة الحالي |
| الرافعة | 50× |
| أقصى المراكز المفتوحة | 3 |
| وقف الخسارة | حركة سعرية 15% من سعر الإشارة |
| جني الربح | حركة سعرية 1.8% من سعر الإشارة |
| شرط الحركة | تتجاوز ±1.2% بين الإغلاق الحالي وإغلاق قبل دقيقتين |
| شرط الحجم | أكبر من 3.5× متوسط الشموع `[-15:-3]` |
| ضغط دفتر الأوامر | أكبر من 0.35 للشراء، وأقل من −0.35 للبيع |
| قائمة المراقبة | أعلى 40 عقدًا مؤهلًا بالسيولة، بحجم يومي أدنى 15 مليون USDT |
| متابعة الإشارات | مستمرة بتحديثات WebSocket |
| تحديث قائمة العملات | كل 600 ثانية؛ ليس انتظارًا بين فحوص الإشارات |
| مراقبة الخروج | كل 8 ثوانٍ |
| تبريد الدخول للعملة | 8 ثوانٍ |
| الرسوم الافتراضية | 0.05% لكل تنفيذ |

الإعدادات الموثقة موجودة أيضًا في `baseline.json`. القيم التنفيذية في `binance_cascade_hunter_dynamic_v2.py`، وتتحقق الاختبارات من تطابقها مع النسخة المعتمدة. مثلًا: محفظة 100 USDT تعطي هامشًا يقارب 10 USDT وقيمة مركز تقارب 500 USDT قبل التقريب والرسوم.

## التثبيت والتحديث على تيرمكس / أوبونتو

داخل أوبونتو، من نسخة المستودع الموجودة:

```bash
cd ~/Final
python3 -m venv .venv
source .venv/bin/activate
git pull --ff-only
python -m pip install -r requirements.txt
```

يتطلب Python 3.11 أو أحدث. إذا كانت المحاكاة تعمل، أوقفها بـ Ctrl+C وانتظر ظهور مؤشر الأوامر قبل التحديث. لا تشغّل أكثر من عملية على ملف الحالة نفسه.

## التشغيل الأساسي مع لوحة المتابعة

افتح [لوحة المتابعة الخاصة](https://cascade-v2-khaled-live.tinyfairy8192.chatgpt.site/) بحساب ChatGPT نفسه، ثم «ربط تيرمكس» ← «تنزيل ملف الربط». انقل `dashboard-config.json` من تنزيلات الهاتف إلى مجلد `Final` داخل أوبونتو:

```bash
cd ~/Final
source .venv/bin/activate
cp /sdcard/Download/dashboard-config.json .
python -u run_paper_live.py 2>&1 | tee -a live-paper-live.log
```

إذا تعذر النسخ من `/sdcard/Download/`، تحقّق من اسم الملف وصلاحية وصول تيرمكس إلى التخزين. لا تطبع محتوى ملف الربط؛ يحتوي رمز وصول خاصًا باللوحة. لا يحتاج البوت مفاتيح Binance.

عند ظهور `DASHBOARD CONNECTED` يرسل الهاتف التحديثات كل 10 ثوانٍ. تطلب اللوحة التحديث كل 5 ثوانٍ وتعرض وقت آخر استلام. إذا تأخر الاستلام 40 ثانية تُظهر انقطاع التحديث. تعذر رفع البيانات لا يوقف المحاكاة المحلية.

كل تشغيل بالأمر الأساسي يبدأ **جلسة جديدة بـ100 USDT** باسم ملف فريد مثل `paper_state_live_YYYYMMDD_HHMMSS_ID.json`، مع الاحتفاظ بالجلسات السابقة. لا تبدأ محاكاة جديدة لمجرد إعادة تشغيل جلسة سابقة؛ استخدم الاستعادة:

```bash
python -u run_paper_live.py --resume paper_state_live_YYYYMMDD_HHMMSS_ID.json
```

استبدل الاسم بملف الجلسة الفعلي الذي يظهر في السجل. الإيقاف بـ Ctrl+C يحفظ الحالة ويحاول إرسال حالة التوقف، ويترك المراكز الورقية المفتوحة في ملف الجلسة للاستعادة. تبقى مراقبة السوق والخروج متوقفة حتى تشغيل الجلسة مجددًا.

## تفاصيل الصفقات والتصدير

اللوحة تعرض الجلسات، والرصيد، وقيمة المحفظة، والمراكز المفتوحة، وأسعار وأوقات الدخول والخروج، والكمية والرسوم والربح، وسبب الدخول والخروج. يمكن تنزيل الصفقات بصيغة CSV.

يحفظ السجل قياسات الحركة والحجم وضغط الدفتر عند الدخول، وسبب TP/SL وسعر الرصد عند الخروج. سعر تنفيذ المحاكاة يُجلب منفصلًا وقد يختلف عن سعر الإشارة أو رصد الخروج. صافي الصفقة المغلقة يطرح رسوم الدخول والخروج معًا؛ ربح المركز المفتوح غير محقق. تظهر قياسات السجلات القديمة التي لم تُحفظ كبيانات غير متوفرة.

## التشغيل المحلي الاختياري

لتشغيل V2 نفسها دون نشر تحديثات للوحة:

```bash
python -u binance_cascade_hunter_dynamic_v2_paper.py 2>&1 | tee -a live-paper-v2.log
```

هذا الأمر يستعيد `paper_state_dynamic_v2.json` تلقائيًا إن وُجد. يمكن تحديد ملف مختلف باستخدام `--state`. خيار `--reset` يستبدل حالة الملف المختار بحساب جديد؛ لا تستخدمه لاستعادة محاكاة سابقة.

## تنظيم المشروع

| الملف | الدور |
|---|---|
| `run_paper_live.py` | التشغيل الأساسي وإرسال التحديثات الخاصة |
| `binance_cascade_hunter_dynamic_v2_paper.py` | حساب V2 والتشغيل المحلي الاختياري |
| `binance_cascade_hunter_dynamic_v2.py` | منطق الاستراتيجية وإعداداتها |
| `continuous_scanner.py` | الإشارات المستمرة وتحديث قائمة العملات |
| `paper_runtime.py` | دورة التشغيل وربط الاستراتيجية بالمحاكاة |
| `paper_account.py` | التنفيذ الافتراضي والرصيد وحفظ الحالة |
| `baseline.json` | تعريف النسخة والإعدادات المعتمدة |
| `tests/` | اختبارات النسخة الأساسية |

مصدر لوحة Sites محفوظ في مستودع استضافة مستقل؛ هذا المستودع يحتوي البوت والمرسل وتعليمات الربط. ملفات الحالة والسجلات ورمز الربط محلية ولا تُرفع إلى GitHub. تحديث المشروع لا يحذف جلسات الهاتف. تبقى النسخ السابقة متاحة في تاريخ Git وفرع الأرشيف.

## الاختبارات وحدود المحاكاة

```bash
python -m unittest discover -s tests -v
python run_paper_live.py --help
```

الاختبارات تستخدم بيانات وخدمات وهمية للتحقق من المنطق والحفظ والرفع؛ ليست نتائج تداول أو اختبارًا تاريخيًا. لا يحاكي النموذج التصفية أو هامش الصيانة أو التمويل أو الانزلاق. وقف 15% هو نسبة **السعر**؛ عند رافعة 50× لا يمثل حماية واقعية من التصفية. يتطلب استمرار المحاكاة بقاء تيرمكس والاتصال بالسوق قيد التشغيل.
