# Cascade Hunter V2 — النسخة المعتمدة

محاكاة ورقية ببيانات Binance USDT-M المباشرة، دون مفاتيح API أو أوامر حقيقية.

- الرصيد الافتراضي الابتدائي: 100 USDT.
- هامش كل صفقة: 10% من رصيد المحفظة الحالي، برافعة 50×.
- أقصى المراكز المفتوحة: 3.
- وقف الخسارة: 15% من سعر الإشارة؛ جني الربح: 1.8%.
- متابعة مستمرة عبر WebSocket؛ تحديث قائمة أعلى 40 عقدًا سيولة كل 10 دقائق.
- بقيت شروط الحركة والحجم وضغط دفتر الأوامر كما هي.
- رسم افتراضي 0.05% لكل تنفيذ؛ النموذج لا يحاكي التصفية أو التمويل أو الانزلاق.

## التشغيل

```bash
cd ~/Final
source .venv/bin/activate
pip install -r requirements.txt
python -u binance_cascade_hunter_dynamic_v2_paper.py 2>&1 | tee -a live-paper-v2.log
```

الإيقاف: Ctrl+C. يستعيد التشغيل التالي المحفظة والصفقات تلقائيًا من `paper_state_dynamic_v2.json`؛ لا تستخدم `--reset` إلا لبدء حساب جديد وحذف حالته السابقة.

## الملفات

- `binance_cascade_hunter_dynamic_v2_paper.py`: نقطة تشغيل المحاكاة المعتمدة.
- `binance_cascade_hunter_dynamic_v2.py`: منطق وإعدادات V2.
- `continuous_scanner.py`: متابعة السوق والإشارات المستمرة.
- `paper_runtime.py`: إدارة مهام المحاكاة.
- `paper_account.py`: الرصيد والتنفيذ الافتراضي وحفظ الحالة.
- `tests/`: اختبارات النسخة المعتمدة فقط.

اسم ملف الحالة وصيغته وإعداداته محفوظة لتوافق جلسات V2 السابقة. السجلات والحالات المحلية غير المرفوعة إلى GitHub لا تتأثر بتحديث المستودع.

```bash
python -m unittest discover -s tests -v
```

## المتابعة عبر الرابط

[لوحة متابعة V2 الخاصة](https://cascade-v2-khaled-live.tinyfairy8192.chatgpt.site)

افتح اللوحة بحساب ChatGPT نفسه، واضغط «ربط تيرمكس» ثم نزّل `dashboard-config.json` وانقله إلى مجلد `Final` داخل أوبونتو. ملف الربط يحتوي اعتماد وصول خاص؛ لا ترفعه إلى GitHub ولا تشاركه.

```bash
cd ~/Final
source .venv/bin/activate
git pull --ff-only
cp /sdcard/Download/dashboard-config.json .
python -u run_paper_live.py 2>&1 | tee -a live-paper-live.log
```

كل تشغيل بهذا الأمر يبدأ محفظة جديدة مستقلة برصيد افتراضي 100 USDT، وملف حالة جديد باسمه وتوقيته. يحفظ كل الجلسات السابقة. لاستعادة جلسة محددة:

```bash
python -u run_paper_live.py --resume paper_state_live_YYYYMMDD_HHMMSS_ID.json
```

يرسل الهاتف البيانات كل 10 ثوانٍ، وتطلب اللوحة التحديث كل 5 ثوانٍ. تعرض اللوحة وقت آخر استلام، وتبيّن تأخر التحديث بعد 40 ثانية. تستمر المحاكاة محليًا إن تعذر الرفع. إيقافها بـ Ctrl+C يحفظ الحالة ويرسل حالة التوقف عند توفر الاتصال، ولا يغلق المراكز الورقية المفتوحة تلقائيًا. اختيار جلسة من اللوحة يعرض صفقاتها؛ ويمكن تنزيل جميع صفقاتها كملف CSV.

تُحفظ قياسات الحركة والحجم وضغط الدفتر مع الدخول، وTP/SL وسعر الرصد مع الخروج. الملفات القديمة لا تحتوي بالضرورة هذه القياسات، وتعرضها اللوحة كبيانات غير محفوظة. صافي ربح الصفقة المغلقة يطرح رسوم الدخول والخروج معًا؛ ربح المركز المفتوح غير محقق. تظل متابعة الأسعار والخروج مرتبطة بتشغيل تيرمكس والاتصال بالسوق.
