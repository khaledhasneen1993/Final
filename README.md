# Cascade Hunter V2 — النسخة المعتمدة

محاكاة ورقية ببيانات Binance USDT-M المباشرة، دون مفاتيح API أو أوامر حقيقية.

- الرصيد الافتراضي الابتدائي: 100 USDT.
- هامش كل صفقة: 10% من رصيد المحفظة الحالي، برافعة 50×.
- أقصى المراكز المفتوحة: 3.
- وقف الخسارة: 15% من سعر الإشارة؛ جني الربح: 1.8%.
- متابعة مستمرة عبر WebSocket؛ تحديث قائمة أعلى 40 عقدًا سيولة كل 10 دقائق.
- بقيت شروط الحركة والحجم وضغط دفتر الأوامر كما هي.
- رسم افتراضي 0.05% لكل تنفيذ؛ النموذج لا يحاكي التصفية أو التمويل أو الانزلاق.

## التشغيل

```bash
cd ~/Final
source .venv/bin/activate
pip install -r requirements.txt
python -u binance_cascade_hunter_dynamic_v2_paper.py 2>&1 | tee -a live-paper-v2.log
```

الإيقاف: Ctrl+C. يستعيد التشغيل التالي المحفظة والصفقات تلقائيًا من `paper_state_dynamic_v2.json`؛ لا تستخدم `--reset` إلا لبدء حساب جديد وحذف حالته السابقة.

## الملفات

- `binance_cascade_hunter_dynamic_v2_paper.py`: نقطة تشغيل المحاكاة المعتمدة.
- `binance_cascade_hunter_dynamic_v2.py`: منطق وإعدادات V2.
- `continuous_scanner.py`: متابعة السوق والإشارات المستمرة.
- `paper_runtime.py`: إدارة مهام المحاكاة.
- `paper_account.py`: الرصيد والتنفيذ الافتراضي وحفظ الحالة.
- `tests/`: اختبارات النسخة المعتمدة فقط.

اسم ملف الحالة وصيغته وإعداداته محفوظة لتوافق جلسات V2 السابقة. السجلات والحالات المحلية غير المرفوعة إلى GitHub لا تتأثر بتحديث المستودع.

```bash
python -m unittest discover -s tests -v
```
