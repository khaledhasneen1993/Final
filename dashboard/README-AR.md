# لوحة واحدة للبوتين من GitHub

واجهة عربية محلية لتشغيل Final وFinal-2 ومتابعتهما. الكود يأتي من مستودعي GitHub؛ لا ZIP ولا نسخ يدوية لملفات Python. التشغيل على الهاتف يتطلب تنزيل الكود والمكتبات وحفظ ملفات الحساب محليًا؛ رابط GitHub ليس خادمًا ينفذ البوت عن بعد.

## أول تشغيل للمستخدم الحالي

البوتان القديمان متوقفان. داخل أوبونتو الذي يعمل داخل Termux:

```bash
apt update
apt install -y git python3 python3-venv ca-certificates
cd /root
git clone --branch dual-bot-dashboard https://github.com/khaledhasneen1993/Final.git cascade-git
cd /root/cascade-git
CASCADE_RUNTIME_DIR=/root/cascade-termux bash run_dashboard.sh
```

اخترنا مجلد Git جديدًا `cascade-git` للمحافظة على التثبيت السابق. الأمر الأخير ينزل Final-2 تلقائيًا من فرع main إلى `.runtime/repos/Final-2` ويثبت المكتبات في `.venv-dashboard` ثم يبدأ الخادم والبوتين. يحتفظ بمسار الحساب المختار في `.runtime/account-location`، فيمكن التشغيل اللاحق بالأمر:

```bash
cd /root/cascade-git
bash run_dashboard.sh
```

إذا ظهر أن مجلد cascade-git موجود، لا تعِد clone فوقه. إذا كان هو النسخة نفسها، ادخله وتحقق من `git status` و`git branch --show-current` قبل التشغيل أو التحديث. لا تستبدل نسخة محلية مختلفة قسرًا.

الخادم يستمع على http://127.0.0.1:8787 فقط؛ افتحه من متصفح الهاتف نفسه. إن بقيت الواجهة القديمة ظاهرة أعد تحميل الصفحة. لا تفتح العنوان عبر HTTPS، ولا تشغل الخادم القديم والجديد معًا.

المسار `/root/cascade-termux` يعيد استخدام `data/final.state.json` و`data/final2.state.json` والسجل والمنحنى الموجودين. لا تنقل data ولا تستخدم reset: قد توجد مراكز مفتوحة محفوظة تستأنف إدارتها من الأسعار الحالية. القفل المشترك يمنع تشغيل النسخة القديمة والجديدة على الحساب نفسه.

إذا لم يتوفر ملف حالة في المسار المختار، يبدأ ذلك البوت حسابًا افتراضيًا جديدًا بـ100 USDT. إعدادات غير متوافقة تؤدي إلى خطأ ظاهر في سجل البوت؛ لا يعاد ضبط الحساب تلقائيًا. الملفات الحالية المحدثة لـFinal-2 متوافقة مع 5% هامش و5% وقف وتعزيز واحد عند 2.5% وخمسة مراكز.

## محتوى اللوحة

- اختيار البوتين معًا أو بوت واحد، مع تشغيل وإيقاف وحفظ لكل منهما.
- نظرة عامة: قيمة المحفظة، الرصيد، غير المحقق، الهامش والمتاح، صافي المغلق، الرسوم والنجاح، منحنى قيمة المحفظة ومصدر الكود الفعلي.
- المراكز: عرض مختصر للهاتف وجدول للحاسوب، الاتجاه ووقت الدخول ومتوسط التنفيذ وآخر سعر محفوظ والحجم والهامش والهدف والوقف والتعزيز والتفاصيل.
- الصفقات: بحث بالعملة، صفحات من 30 سجلًا، تبديل بين الصفقات المغلقة وكل التنفيذات، وصافي المغلق بعد جميع رسومه.
- حالة البيانات: أحداث السوق وفحوص دفتر الأوامر والدخولات، وعدد العملات الحديثة ومعلومات كل عملة عن آخر حدث مقبول وعمر توقيته وتهيئة الشموع.
- الإعدادات والسجل، وتصدير الصفقات والتنفيذات CSV وكامل لقطة المراجعة JSON.

تحدّث الواجهة كل 3 ثوانٍ، وأسعار المراكز حسب دورة البوت الأصلية. أرقام الماسح تبدأ من الصفر عند تشغيل العملية، وسجل الصفقات يبقى محفوظًا. منحنى القيمة يسجل كل 30 ثانية عند وجود بيانات حديثة، ويحتفظ بآخر 30 يومًا ويعرض آخر 600 عينة. الوقت حسب الجهاز.

## نطاق التغيير

هذه الإضافة لا تعدل ملفات الاستراتيجية أو الماسح في أي بوت: شروط الحركة والحجم ودفتر الأوامر، الأحجام، الوقف والهدف والتعزيز وعدد المراكز محفوظة. الغلاف يستدعي V2PaperHunter لـFinal وFinal2PaperHunter من ريبو Final-2 في عمليتين منفصلتين. لا يستدعي ناشري البيانات السحابيين ولا يحتاج رموز اللوحات السابقة.

تعرض الواجهة تأخر البيانات لكل عملة بدل اعتبار اتصال WebSocket وحده دليلًا على وصول بيانات كل العملات. مشكلة التعافي السريع من تجمد التحديثات في الماسح الأصلي لم تعدل ضمن هذا الطلب؛ العرض الجديد يكشفها دون تغيير تشغيل الاستراتيجية أو فرض صفقات.

## الإيقاف والعمل بالخلفية

Ctrl+C يوقف الخادم والبوتين ويحفظ الحالة. إيقاف بوت لا يغلق مراكزه، ويوقف فحص الوقف والهدف حتى الاستئناف. لا تسحب تطبيق Termux لإغلاقه قسرًا.

للخلفية، بعد إيقاف الخادم الأمامي اكتب `exit` للعودة من أوبونتو إلى Termux الأساسي، ثم:

```bash
termux-wake-lock
tmux new-session -d -s cascade-git 'proot-distro login cascade-ubuntu -- bash -lc "cd /root/cascade-git && exec bash run_dashboard.sh"'
```

لمتابعة الطرفية `tmux attach-session -t cascade-git`، وللفصل مع استمرار التشغيل Ctrl+B ثم D. للإيقاف الكامل من Termux:

```bash
tmux send-keys -t cascade-git C-c
```

اجعل استخدام بطارية Termux غير مقيّد. tmux وWake lock لا يضمنان بقاء أندرويد على تشغيل التطبيق إذا أوقفه النظام أو أعيد تشغيل الهاتف.

## تحديث Git

أوقف الخادم والبوتين أولًا. داخل أوبونتو:

```bash
cd /root/cascade-git
git pull --ff-only
git -C .runtime/repos/Final-2 pull --ff-only
bash run_dashboard.sh
```

لا يوجد تحديث تلقائي للكود أثناء المحاكاة. راجع تغييرات إعدادات الاستراتيجية قبل تحديث مصدر Final-2؛ إذا تغيرت، قد تتطلب جلسة موجودة ترحيلًا صريحًا. لا ترفع data أو السجلات أو رموز الربط إلى GitHub.

لمستخدم جديد لا يملك الحزمة القديمة، يكفي `bash run_dashboard.sh` دون CASCADE_RUNTIME_DIR؛ تحفظ حساباته في `.runtime/data`. يمكن تحديد مصدر Final-2 الموجود مسبقًا عبر CASCADE_FINAL2_DIR، وتحديد مسار حساب آخر عبر CASCADE_RUNTIME_DIR. إذا اخترت مصدرًا مخصصًا، حدده في كل تشغيل كما في المرة الأولى.

النموذج الورقي الأصلي يستثني التصفية والتمويل والانزلاق، ولا يمثل حساب Futures حقيقيًا بدقة.
